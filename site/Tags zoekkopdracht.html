Betekenissen van tags

Hier zal ik paar tags uitleggen!

header

Een header is het bovenste stukje van een webpagina of een sectie, dat gebruikt wordt als inleiding.

nav

nav staat voor navigation en bewaart een set links, specifiek de belangrijkste menu's op een website zodat gebruikers gemakkelijk kunnen navigeren.

main

De main-tag in HTML geeft aan wat de belangrijkste inhoud van een webpagina is. Het bevat de hoofdinhoud van een website

footer

Een footer is het onderste stukje van een webpagina dat je op bijna elke pagina van een website terugvindt.

article

Article wordt gebruikt voor het defineren van de inhoud van een webpagina.

aside

De aside-tag wordt gebruikt om een ​​gedeelte van een tekst weer te geven dat indirect verband houdt met de hoofdinhoud.

a

De a-tag is een link waarmee je een webpagina verbindt met een andere pagina of website.

img

De img-tag gebruik je om een afbeelding te tonen op je webpagina.
